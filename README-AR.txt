- Overview: Settings ← بطاقة Overview ← Load overview: عدد الطلاب والمشتركين والمجانيين والمنتهين، الجدد هذا الأسبوع، من فتح التطبيق في 7 و30 يوماً، دخل هذا الشهر والشهر الماضي (الدفعات الحقيقية المفعّلة فقط)، وقائمة الاشتراكات التي تنتهي خلال 7 أيام مع زر WhatsApp reminder.

كل كتاب كامل (16 نوفمبر 2026):
- كل كتاب JSON يُستورد كاملاً. المكرر يُتجاهل فقط إذا كان نفس السؤال (نفس النص والخيارات) في نفس الكتاب، أو تكرر في نفس الملف. الكتاب الذي يشارك أسئلة مع كتاب آخر يُستورد كاملاً، وبطاقة Book check تخبرك فقط بعدد الأسئلة المشتركة ولا تسألك ولا تستبعد شيئاً.
- إذا كان اسم الكتاب نفسه مكتوباً بشكل مختلف قليلاً (حروف كبيرة، مسافات، علامات ترقيم) يُحفظ تحت الاسم الموجود لأنه نفس الكتاب.
- إصلاح: سؤالان مختلفان يحملان نفس المعرّف (uid) داخل ملف JSON كان أحدهما يُستبعد كأنه مكرر. الآن لا يُعتبر مكرراً إلا نفس النص والخيارات.
- إصلاح: عند النشر يحصل كل سؤال على معرّف خاص به، فلا يندمج سؤالان في سؤال واحد عند الطالب.
- لوحة المدير فيها الآن Different questions بجانب Questions: عدد الأسئلة المختلفة، وهو نفس العدد الذي يراه الطالب في الدراسة العامة (السؤال الموجود في كتابين يُحسب مرة).
- إصلاح: زر Delete One Book لم يكن يعرض الكتب التي جاء اسمها من داخل ملف JSON. الآن تعرض القائمة كل الكتب مع عدد أسئلتها، والحذف يزيل الكتاب كاملاً ويخبرك قبله كم سؤالاً سيضيع نهائياً.
- Import ← Books stored twice: لدمج كتابين هما في الحقيقة كتاب واحد (اختياري).
- Publish يستبدل بنك الطالب بالكامل بما في نسخة المدير.

- رفع أسئلة JSON يطابق الأسماء مع التصنيف: الفروق البسيطة (حروف كبيرة، مسافات) تُصحَّح تلقائياً، والأسماء غير الموجودة تظهر في تقرير مع زر Add the missing names to the classification.

- الكتب والمكرر: كل كتاب JSON يُستورد كاملاً حتى لو تكررت أسئلته في كتاب آخر؛ المكرر داخل نفس الكتاب فقط يُتجاهَل. زر Remove Repeats Inside a Book لا يحذف نسخة كتاب آخر. الكتب التي رفعتها سابقاً ناقصة: أعد رفع ملف كل كتاب فيضيف الناقص فقط.

تعديل اسم الكتاب (جديد):
Import & Export ← قسم Rename a Book (بجانب Delete One Book): اختر الكتاب واكتب الاسم الجديد ثم أكّد. يتغير الاسم في كل أسئلة الكتاب (حقلا book وgroup) وفي محاضراته وبيانات الكتاب ضمن التخصص المفتوح، وتُنظَّف المسافات الزائدة. إن كان الاسم الجديد موجودًا لكتاب آخر (بغض النظر عن حالة الأحرف) يُدمج الكتابان تحت الاسم الموجود. تُحدَّث علامة updatedAt للسجلات المتغيرة لتصل التسمية الجديدة مع حزمة التحديث التالية أو الحزمة المنشورة، فصدّر أو زامن التحديث بعد التعديل ليراه الطلاب. يعمل في وضع Admin فقط ولا يعمل في تخصص مؤرشف (للقراءة فقط).

الجديد:
1. صار التطبيق منصة بنك أسئلة لعدة تخصصات. ENT هو الآن تخصص واحد بين تخصصات، وتبقى هويته ومحتواه كما كانا.
2. الهرم: تخصص ← تصنيف (Category) ← قسم (Section) ← سؤال. كل سؤال يتبع تخصصًا واحدًا فقط، ولا تختلط بيانات التخصصات أبدًا.
3. التخصصات: اضغط شارة التخصص أعلى الشاشة ← Specialties: إنشاء، تعديل، تفعيل، تعطيل، أرشفة، إعادة ترتيب، فتح مساحة التخصص. المعرّف (id) دائم، والتخصصات لا تُحذف بل تُؤرشف. التخصص المؤرشف للقراءة فقط.
4. لكل تخصص مساحة عمل ببيانات منفصلة (أسئلة، تصنيفات، نسخ احتياطية، استيراد، تصدير، أسئلة مجانية، بلاغات). تظهر شارة التخصص المفتوح وشريط تنبيه دائمًا.
5. التصنيفات والأقسام: Specialties ← Categories & sections: إضافة، إعادة تسمية (تتحدّث الأسئلة تلقائيًا)، ترتيب، نقل قسم، أرشفة، حذف عند عدم الاستخدام. ترتيب الأسئلة نفسها يبقى حسب الإنشاء، ويُنقل السؤال بزر Reclassify.
6. الحزم: صيغة جديدة .qbpkg (schemaVersion 2) تحمل التخصص. تُرفض حزمة أي تخصص آخر كاملةً قبل كتابة أي شيء. تُقبل أيضًا .entpkg القديمة وتُعامل كـ ENT. تصدير ENT فيه خيار Compatible with app 1.3.x لطلاب ما زالوا على 1.3.x.
7. النشر السحابي لكل تخصص على حدة (packs/<id>) بنافذة تأكيد تذكر التخصص، ويُرفض الكتابة فوق بنك تخصص آخر. نطاق الاشتراك Subscription scope: selected (تخصص الطالب فقط) أو all.
8. حسابات الطلاب والبلاغات تعرض التخصص مع فلترة، وتغيير تخصص طالب أو الموافقة على طلبه، وزر ترحيل حسابات 1.3.x إلى ENT.
9. أمان: أُزيلت كلمة مرور المدير الثابتة التي كانت داخل app.js. أول مرة تفتح فيها وضع المدير تختار رمزًا (8 أحرف على الأقل) محفوظًا كبصمة مملّحة على الجهاز فقط. هذا يخفي الشاشات محليًا؛ الحماية الحقيقية قواعد Firestore ومستند admins/{uid}.
10. ملفات جديدة: firebase/firestore.rules (+ اختبارها)، FIREBASE-SETUP.md، FIREBASE-SETUP-AR.md، MIGRATION.md، README.md.

Adam ENT — الإصدار 1.3.0 — الحسابات والاشتراك والإبلاغ عن الأسئلة

الجديد في هذا الإصدار:
1. نسخة الطالب: شاشة دخول (اسم مستخدم أو بريد + كلمة مرور) مع Create an account. يبقى الطالب مسجّلًا ويعمل التطبيق دون اتصال بعد أول دخول.
2. الأسئلة المجانية: تحدد أنت الأسئلة المجانية بزر Free في قائمة الأسئلة بنسخة المدير (العدّاد يقارنها بـ 100). ثم Settings ← Export Free Pack، وضع الملف free-pack.entpkg بجانب index.html في نسخة الطالب قبل نشرها.
3. الاشتراك: بدونه يرى الطالب الأسئلة المجانية فقط. زر Subscribe يفتح واتساب برقمك مع الخطة واسم الحساب. تفعّل الحساب من نسخة المدير: Settings ← Student accounts (+1 / +3 / +12 شهرًا، أو تاريخ محدد، أو إيقاف).
4. بنك الأسئلة الكامل: من نسخة المدير Settings ← Cloud (Firebase) ← Publish question bank. ينزّله الطالب الفعّال تلقائيًا (مضغوطًا ومتحققًا منه). وعند انتهاء الاشتراك يُحجب البنك ويبقى تقدم الطالب وملاحظاته وإشاراته محفوظة، ويعود كل شيء فور التجديد.
5. الإبلاغ عن سؤال: زر Report a problem عند الطالب. تصلك البلاغات في Settings ← Question reports بنسخة المدير، مع Show question وResolve.
6. مسح التقدم: زر Reset My Progress في إعدادات الطالب.
7. أُزيل النسخ الاحتياطي التلقائي في localStorage لأنه كان يفشل مع حجم البنك ولم تكن نافذة استعادته تظهر عمليًا.

قبل النشر (مرة واحدة): اتبع FIREBASE-SETUP-AR.md. عبّئ firebase-config.js في النسختين وsubscription-config.js في نسخة الطالب، وانشر firestore.rules. حتى تُعبَّأ الإعدادات تعرض نسخة الطالب "Sign-in is not set up yet".
